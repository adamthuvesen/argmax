# Design explorations

variant shipped, `index.html` is the comparison harness, and the PNGs are
the frames it compared. The governing docs are [styling.md](../styling.md)
(desktop) and [chat-cards.md](../chat-cards.md) (chat surface). These
folders are evidence for a decision, not a spec to build from.
