# Plans

Dated design snapshots, written before or during a build. They record why a
design was chosen on the day it was decided, and they are **not** kept current.
When a plan and the code disagree, the code and the matching subsystem doc
(see the index in [AGENTS.md](../../AGENTS.md)) are right. Fix the subsystem
doc in the same change as the code; touch a plan only to correct a fact that
would mislead a reader of the snapshot.
